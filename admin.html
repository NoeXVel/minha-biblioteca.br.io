Painel

Publique um sistema novo direto daqui. Isso salva os arquivos no seu repositório do GitHub automaticamente — o site atualiza sozinho em 1-2 minutos.

ainda não configurado

1. Configuração (só uma vez)

Você precisa de um token do GitHub para o painel poder publicar por você. Isso é como uma senha exclusiva para este repositório. Ela fica guardada só neste navegador — nunca é enviada pra mim nem pra ninguém além do GitHub.

  1. Acesse github.com/settings/personal-access-tokens/new (token "fine-grained").
  2. Em Repository access, escolha Only select repositories e selecione o repositório do seu site.
  3. Em Permissions → Repository permissions, ache Contents e mude para Read and write.
  4. Clique em Generate token e copie o código gerado (começa com github_pat_...).

2. Publicar um sistema novo

Cole o link do Release com o arquivo do sistema e preencha as informações. A documentação é opcional — se deixar em branco, o painel cria uma página simples que você pode melhorar depois.
